# Smart Harness Copilot plugin

Generated from canonical Smart Harness v0.8.0 sources. Install with `copilot plugin install lmathia2/coding_tools:smart-harness/packages/copilot`.

Plugin installation supplies host workflows, specialists, skills, tools, and the inactive-by-default stop hook. Use the repository installer instead when the workflow/configuration files should be versioned with a project.
